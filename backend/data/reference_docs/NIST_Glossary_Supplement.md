# NIST CSRC Glossary (supplementary definitions)

## Core Security Concepts

**Cybersecurity**: The process of protecting information by preventing, detecting, and responding to attacks. (Source: NIST Cybersecurity Framework v1.1.) Also defined as: the ability to protect or defend the use of cyberspace from cyber attacks. (Source: NISTIR 8170, from CNSSI 4009.)
